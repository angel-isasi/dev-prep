# Programar: palabras básicas

## En una frase

Ya escribes `function`, `return` y `const` en tu código; aquí aprendes a **decirlas en voz alta** y a usarlas en frases, como en una daily o en una entrevista técnica.

## Cómo se forma

Agrupa las palabras según dónde las oyes:

| Dónde | Palabras | Frase modelo |
|---|---|---|
| Dentro del código | function, variable, array, object, loop, return | This function **returns** an array. |
| React | component, state, props, hook, render | The component **renders** a list. |
| Errores | bug, error, warning, fix, debug | I **fixed** the bug. |
| Git | branch, commit, merge, pull request, review | Can you **review** my pull request? |
| Web y datos | server, client, request, response, database | The server sends a **response**. |
| Entregar | build, deploy, release, version | We **deploy** on Fridays. |

- Muchas palabras son sustantivo y verbo a la vez: **a fix / to fix**, **a commit / to commit**, **a test / to test**, **a build / to build**.
- Las siglas se deletrean en inglés: **API** → éi pi ái, **URL** → iú ar él. **JSON** se lee como palabra: yéison.
- Verbos irregulares de la unidad: **build → built**, **throw → threw**, **catch → caught**.

Ejemplos:
- I fixed the bug in the login form. → Arreglé el error del formulario de inicio de sesión.
- The function returns a string. → La función devuelve un string.
- We're going to deploy tomorrow. → Vamos a desplegar mañana.

## Errores típicos

- "I fixed the error of the login" ✗ → "I fixed the bug **in** the login" ✓. Un error del código es un **bug in** algo.
- "I did a commit" ✗ → "I **made** a commit" o simplemente "I **committed** the changes" ✓.
- "The function returns a string" ✓, no "the function return a string" ✗: con **it** el verbo lleva **-s**.
- "The datas" ✗ → "the **data**" ✓. **Data** no lleva -s en el uso normal.
- "Parameter" y "argument" no son lo mismo: el **parameter** está en la definición, el **argument** es el valor que pasas al llamar la función.

## Pronunciación

- **array** → aréi, **null** → nál, **boolean** → búlian, **deploy** → diplói: el acento va donde está la tilde.
- **method** → mézod: la "th" se dice con la lengua entre los dientes, como una "z" de España.
- **data** → déira y **database** → déirabeis: no digas "dáta".
- **query** → kuíri (no "kéri") y **JSON** → yéison.
