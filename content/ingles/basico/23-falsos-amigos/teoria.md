# Falsos amigos

## En una frase

Un falso amigo es una palabra que se parece a una del español pero significa otra cosa. Si le escribes a tu jefe "I'm **constipated**" porque tienes gripe, va a entender que estás estreñido.

## Cómo se forma

Para cada falso amigo aprende tres cosas: lo que parece, lo que significa y cómo se dice lo que querías decir.

| Inglés | Parece | Significa | Lo que querías decir |
|---|---|---|---|
| actually | actualmente | en realidad | currently |
| actual | actual | real, verdadero | current |
| assist | asistir | ayudar | attend |
| attend | atender | asistir (a una reunión) | serve, help (a un cliente) |
| realize | realizar | darse cuenta | carry out |
| support | soportar | apoyar | put up with |
| discuss | discutir (pelear) | conversar sobre un tema | argue |
| argument | argumento | discusión, pelea | plot (de una película) |
| compromise | compromiso | acuerdo en el que ambos ceden | commitment |
| introduce | introducir | presentar a alguien | insert, enter |
| notice | noticia | notar, aviso | news |
| resume | resumir | continuar | summarize |
| résumé | resumen | currículum (CV) | summary |
| career | carrera universitaria | trayectoria profesional | major |
| college | colegio | universidad | school |
| library | librería | biblioteca | bookstore |
| lecture | lectura | clase magistral, charla | reading |
| exit | éxito | salida | success |
| eventually | eventualmente | al final, tarde o temprano | occasionally |
| sensible | sensible | sensato | sensitive |
| carpet | carpeta | alfombra | folder |
| advice | aviso | consejo | warning |

## Errores típicos

- "I'm **constipated**" ✗ (estoy estreñido) → "I **have a cold**" ✓ (estoy resfriado).
- "My friend is very **sympathetic**" ✗ si quieres decir simpático → "very **nice**" o "**friendly**" ✓. Sympathetic es comprensivo.
- "She's **embarrassed**" ✗ si quieres decir embarazada → "She's **pregnant**" ✓. Embarrassed es avergonzado.
- "My **parents** live in Cusco" cuando hablas de tíos y primos ✗ → "My **relatives**" ✓. Parents son solo papá y mamá.
- "The movie was a big **deception**" ✗ (engaño) → "a big **disappointment**" ✓ (decepción).
- "I work in a **fabric**" ✗ (tela) → "in a **factory**" ✓ (fábrica).
- "Can you **assist to** the meeting?" ✗ → "Can you **attend** the meeting?" ✓: attend va sin to.
- "I **realized** the tests" ✗ → "I **ran** the tests" o "I **carried out** the tests" ✓. Realize es darse cuenta.

## Pronunciación

- **resume** (continuar) → rizúm. **résumé** (currículum) → rézumei, con fuerza al inicio.
- **realize** → ríalais, **eventually** → ivénchuali, **actually** → ákchuali.
- **recipe** → résipi: tres sílabas, la e final sí suena.
- **once** → uáns (no "ónse"), **quote** → kuóut, **mayor** → méier.
