## En una frase

**There is** y **there are** son el "hay" del inglés: sirven para describir tu casa, tu cuarto o tu oficina, y para preguntar si algo existe en un lugar.

## Cómo se forma

| | Singular | Plural |
|---|---|---|
| Afirmativo | There's a desk. | There are two chairs. |
| Negativo | There isn't a garage. | There aren't any windows. |
| Pregunta | Is there a microwave? | Are there any shelves? |
| Respuesta corta | Yes, there is. / No, there isn't. | Yes, there are. / No, there aren't. |

- **There's** (there is) es lo normal al hablar. En la respuesta corta afirmativa no se contrae: Yes, there is.
- Si hay una lista, manda la primera cosa: There's a bed and two chairs.
- **some** (algunos, algo de) va en afirmativo: There are some books. / There's some water.
- **any** va en negativo y en preguntas: There aren't any chairs. / Are there any windows?
- **How many ... are there?** → ¿Cuántos ... hay?: How many bedrooms are there?

## Errores típicos

- "Have a table in the kitchen." ✗ → "There's a table in the kitchen." ✓ (para decir "hay" no se usa have)
- "Exist a problem." ✗ → "There's a problem." ✓
- "There is two bathrooms." ✗ → "There are two bathrooms." ✓
- "There are some chairs?" ✗ → "Are there any chairs?" ✓
- "There aren't some windows." ✗ → "There aren't any windows." ✓
- "Yes, there's." ✗ → "Yes, there is." ✓

## Pronunciación

- **there's** suena "dérs": la th suave es como una d con la lengua entre los dientes.
- **furniture** suena "férnicher".
- **kitchen** suena "kíchen": no la confundas con **chicken** ("chíken", pollo).
- **drawer** suena "drór" y **stove** "stóuv".
