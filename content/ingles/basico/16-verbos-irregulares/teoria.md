# Verbos irregulares en pasado

## En una frase

El pasado simple cuenta acciones terminadas ("ayer fui", "el lunes escribí"). Los verbos regulares agregan **-ed** (work → worked), pero los irregulares tienen su propia forma (go → **went**) y hay que memorizarla. Son pocos, pero son los más usados del idioma.

## Cómo se forma

| Tipo de frase | Forma | Ejemplo |
|---|---|---|
| Afirmativa | sujeto + **pasado** | I **went** to Cusco. → Fui a Cusco. |
| Negativa | sujeto + **didn't** + verbo base | I **didn't go**. → No fui. |
| Pregunta | **Did** + sujeto + verbo base | **Did** you **go**? → ¿Fuiste? |
| Con *be* | **was** (I, he, she, it) / **were** (you, we, they) | We **were** at home. → Estuvimos en casa. |

La forma del pasado es la misma para todas las personas: I went, she went, they went. Solo *be* cambia (was / were).

Cada palabra de esta unidad trae tres formas: **base / pasado / participio**. Por ahora usa la del medio. El participio (la tercera) lo usarás después en frases como "I have seen".

Para memorizarlos, agrúpalos:
- **Las tres iguales**: cut, put, let, set, hit, cost, shut, quit, bet, hurt, upset.
- **Pasado y participio iguales**: buy → bought, think → thought, keep → kept, sleep → slept, feel → felt, send → sent.
- **i → a → u**: begin, drink, ring, sing, sink, swim (sing → sang → sung).
- **Tres distintas**: go → went → gone, write → wrote → written, take → took → taken.

## Errores típicos

- "I didn't **went**" ✗ → "I didn't **go**" ✓ (después de *didn't* va el verbo base)
- "Did you **saw** it?" ✗ → "Did you **see** it?" ✓
- "I **goed**" ✗ → "I **went**" ✓
- "He **buyed** a car" ✗ → "He **bought** a car" ✓
- "Yesterday I **go** to work" ✗ → "Yesterday I **went** to work" ✓
- "We **was** late" ✗ → "We **were** late" ✓
- "She **said me**" ✗ → "She **told me**" ✓ (*tell* lleva a la persona; *say* no)

## Pronunciación

- **read** en pasado se escribe igual pero suena "réd", como el color *red*.
- **thought, bought, taught, caught, fought**: suenan "ót" al final; la *gh* no se pronuncia.
- **began, ran, sang, swam**: la *a* suena casi como una *e* abierta ("biguén", "rén"). En **begun, run, sung, swum** suena como una *a* corta ("bigán", "rán").
- **said** suena "séd", no "séid".
