# Phrasal verbs de tecnología 1

## En una frase

Un **phrasal verb** es un verbo + una partícula (up, out, on, into...) que juntos significan otra cosa: **look** es mirar, pero **look up** es buscar un dato. En un equipo de desarrollo se usan todo el tiempo, más que los verbos "formales".

## Cómo se forma

| Tipo | Ejemplo | Con pronombre |
|---|---|---|
| Separable (lleva objeto) | set up the project | set **it** up |
| Inseparable (lleva objeto) | run into a problem | run into **it** |
| Sin objeto | Don't give up. | (no lleva) |
| De tres palabras | come up with an idea | come up with **it** |

- Con los separables, el pronombre (**it, them, me**) va **en medio**: "Back **it** up", "Look **it** up".
- Muchos tienen un sustantivo que se escribe junto: **a setup** / **to set up**, **a backup** / **to back up**, **a login** / **to log in**.
- Los irregulares siguen al verbo base: set → **set**, find → **found**, run → **ran**, come → **came**, go → **went**.

Ejemplos:
- I ran into a problem with the API. → Me topé con un problema con la API.
- Can you set it up on my laptop? → ¿Puedes configurarlo en mi laptop?
- She came up with a better solution. → A ella se le ocurrió una mejor solución.

## Errores típicos

- "Set up it" ✗ → "Set **it up**" ✓. El pronombre nunca va al final en los separables.
- "I need to backup my files" ✗ → "I need to **back up** my files" ✓. **Backup** junto es el sustantivo.
- "She came up an idea" ✗ → "She came up **with** an idea" ✓. Este verbo necesita las tres palabras.
- "I can't find why it fails" ✗ → "I can't **figure out** why it fails" ✓. **Find** es encontrar algo; **figure out** es entender algo difícil.
- "We ran in a problem" ✗ → "We ran **into** a problem" ✓.

## Pronunciación

- La fuerza va en la **partícula**: set **UP**, figure **OUT**, look **UP**.
- Las palabras se unen: **set it up** → sérirap, **look it up** → lúkirap, **figure it out** → fíguiuriráut.
- **figure** → fíguiur, no "figúre".
- **through** (look through) → zrú, con la lengua entre los dientes.
