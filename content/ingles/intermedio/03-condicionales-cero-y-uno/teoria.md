## En una frase

Los condicionales dicen qué pasa si se cumple algo. El **cero** explica reglas que siempre se cumplen, perfecto para describir tu código: If the user clicks, the modal opens. El **uno** habla de algo posible en el futuro: If the tests pass, we'll deploy.

## Cómo se forma

| Tipo | Estructura | Ejemplo | Español |
|---|---|---|---|
| Cero (siempre) | If + presente, presente | If the form is empty, the button is disabled. | Si el formulario está vacío, el botón se desactiva. |
| Uno (futuro posible) | If + presente, will + verbo | If it rains, I'll stay home. | Si llueve, me quedaré en casa. |

- La parte con **if** puede ir al inicio (con coma) o al final (sin coma): I'll call you if I need help.
- **unless** = if... not (a menos que): Unless you save, the tests won't run = If you don't save, the tests won't run.
- **in case** = por si acaso: Take an umbrella in case it rains.
- **as long as** = siempre que: The app works as long as the data is saved.
- **otherwise** = si no, de lo contrario: Save it; otherwise, you'll lose it.
- **whenever** = cada vez que: The spinner appears whenever the app loads data.

Truco para entrevistas: describe tu código como una lista de reglas con if + presente. When también sirve para el cero: When the user types, the list updates.

## Errores típicos

- If it will rain, I'll stay home ✗ → If it rains, I'll stay home ✓ (después de if no va will, aunque hables del futuro).
- If the user click ✗ → If the user clicks ✓ (la -s de tercera persona sigue ahí).
- Unless you don't save ✗ → Unless you save ✓ (unless ya es negativo).
- In case of it rains ✗ → In case it rains ✓ (in case of va con sustantivo: in case of fire).
- If I will have time ✗ → If I have time ✓

## Pronunciación

- **if** es corta, "if", y casi se pega a la palabra siguiente: "ifiu klík" (if you click).
- **I'll / it'll / we'll**: I'll "áil", it'll "ítol", we'll "uíl". En la frase se oyen muy débiles, escúchalos bien.
- **unless** "anlés": la fuerza va al final.
- **behavior** "bijéivior" y **automatically** "otomátikli": en inglés se come la sílaba "ca", no se dice "automáticamente".
