# Phrasal verbs de tecnología 2

## En una frase

Seguimos con phrasal verbs, ahora los que se usan para **organizar el trabajo** (break down, wrap up, take over), **hablar con el equipo** (catch up, reach out, bring up) y **describir lo que pasa con un sistema** (go down, show up, pop up).

## Cómo se forma

| Grupo | Verbos | Frase modelo |
|---|---|---|
| Organizar | break down, split up, put off, wrap up, kick off | Let's **break it down** into tasks. |
| Equipo | catch up, reach out, bring up, point out, count on | I'll **bring it up** at the retro. |
| Encargarse | deal with, sort out, take over, hand over, pick up | I'll **deal with** it. |
| El sistema | go down, show up, pop up, boot up, slow down | The site **went down**. |
| Entornos | turn on/off, spin up, tear down, free up | **Turn it off**, please. |

- Algunos no llevan objeto: "The server **went down**", "The error **shows up** on mobile".
- Otros son inseparables: "**deal with** it", "**count on** me", "**get rid of** it".
- Varios van con una preposición extra: catch up **with** someone, sign off **on** something, fall behind **on** something.

Ejemplos:
- Let's wrap up the meeting. → Cerremos la reunión.
- We need to get rid of this old library. → Tenemos que deshacernos de esta librería vieja.
- The error only shows up on Safari. → El error solo aparece en Safari.

## Errores típicos

- "Turn off it" ✗ → "Turn **it off**" ✓. Como en la unidad anterior, el pronombre va en medio.
- "Get rid off" ✗ → "Get rid **of**" ✓. Es **of**, aunque suene parecido a "off".
- "I'll deal it" ✗ → "I'll **deal with** it" ✓.
- "I need to catch up the team" ✗ → "I need to catch up **with** the team" ✓.
- "He pointed out me" ✗ → "He **pointed it out** to me" ✓. **Point at** es señalar con el dedo; **point out** es hacer notar algo.

## Pronunciación

- **turn off** → ternóf: la "n" se une con la "o".
- **pick it up** → píkirap, **sort it out** → sóriráut: la "t" entre vocales suena casi como una "r" suave.
- **wrap up** → ráp áp: la "w" de **wrap** no se pronuncia.
- **tear down** → tér dáun: este **tear** (romper) rima con "hair"; no es **tear** (lágrima), que se dice tíar.
