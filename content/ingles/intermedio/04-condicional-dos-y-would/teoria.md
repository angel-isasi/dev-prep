## En una frase

El condicional dos habla de situaciones **imaginarias** o poco probables: If I won the lottery, I'd travel → Si ganara la lotería, viajaría. Con **would** y **could** también pides cosas con cortesía, algo clave en el trabajo y en las entrevistas ("What would you do if...?").

## Cómo se forma

**If + pasado simple, would + verbo base**

| Uso | Ejemplo | Español |
|---|---|---|
| Situación imaginaria | If I had more time, I'd learn Python. | Si tuviera más tiempo, aprendería Python. |
| Consejo | If I were you, I'd ask your lead. | Yo que tú, le preguntaría a tu líder. |
| Pregunta hipotética | What would you do if you lost your job? | ¿Qué harías si perdieras tu trabajo? |
| Posibilidad | If we had a budget, we could hire someone. | Si tuviéramos presupuesto, podríamos contratar a alguien. |

- El pasado después de if **no habla del pasado**: muestra que es imaginario.
- **I'd** = I would. Negativa: **wouldn't**.
- **If I were you** es fija para dar consejos (were con todas las personas).

Cortesía (de más directo a más suave):
- Can you help me? → **Could** you help me? → **Would you mind** helping me?
- **Would you mind + -ing**: Would you mind closing the door? Si aceptas: Not at all (no me molesta).
- **Would you like** + sustantivo o to + verbo: Would you like to join us?
- **I'd rather** + verbo base = preferiría: I'd rather work remotely.
- **I wish** + pasado = ojalá (algo que no es así ahora): I wish I had more experience.

## Errores típicos

- If I would have money ✗ → If I had money ✓ (would nunca va en la parte del if).
- If I had money, I'll buy a laptop ✗ → If I had money, I'd buy a laptop ✓
- Would you mind to help me? ✗ → Would you mind helping me? ✓
- I'd rather to stay ✗ → I'd rather stay ✓
- Responder "Yes" a Would you mind...? si quieres ayudar ✗ → "Not at all" o "No problem" ✓ (Yes significa "sí me molesta").

## Pronunciación

- **I'd** "áid", **you'd** "iúd", **she'd** "shíd": la d es muy suave, casi no se oye. Escucha el final: I'd go vs I go.
- **would** "úd" y **could** "kúd": la l no se pronuncia. Rima con good.
- **wouldn't** "údent", casi "údn".
- **Would you** se une: "úyu" (would you mind → "úyu máind").
