# Voz pasiva

## En una frase

La voz pasiva pone primero **lo que pasó** y deja en segundo plano **quién lo hizo**: "The bug **was fixed**" (el error se arregló). Es la forma normal de escribir reportes de errores, changelogs, documentación y mensajes de incidentes.

## Cómo se forma

**Cosa + be + participio** (+ **by** quién, si importa).

| Tiempo | Forma | Ejemplo |
|---|---|---|
| Presente | am / is / are + participio | The app **is deployed** every Friday. |
| Pasado | was / were + participio | The bug **was fixed** yesterday. |
| Presente perfecto | has / have been + participio | The issue **has been resolved**. |
| Con modal | can / will / must be + participio | It **can't be reproduced**. |

- El participio de los regulares termina en **-ed** (fixed, deployed). Los irregulares tienen su forma: written, built, run, found.
- Para preguntar, **be** va primero: "**Was** the PR approved?", "**Is** the build triggered by every push?"
- Usa **by** solo si quién lo hizo es importante: "The bug was reported **by** a customer."

Ejemplos:
- The crash was caused by a null value. → El fallo lo causó un valor null.
- Passwords are encrypted before they're saved. → Las contraseñas se cifran antes de guardarse.
- The root cause hasn't been found yet. → Todavía no se encuentra la causa raíz.

## Errores típicos

- "The bug was fix" ✗ → "The bug was **fixed**" ✓. Después de **be** va el participio.
- "The bug fixed yesterday" ✗ → "The bug **was** fixed yesterday" ✓. Sin **be**, parece que el error arregló algo.
- "Was deleted the file" ✗ → "The file was deleted" ✓. En español dices "se borró el archivo", pero en inglés la cosa va primero.
- "Se usa React" no es "Is used React" ✗ → "React **is used**" ✓.
- "Written for Ana" ✗ → "Written **by** Ana" ✓. Quien hace la acción va con **by**.

## Pronunciación

- La **-ed** suena de tres formas: **fixed** → fíkst (como t), **deployed** → diplóid (como d), **updated** → ápdeirid (sílaba extra después de t o d).
- **was** casi no se oye en la frase: "the bug was fixed" → de bág uoz fíkst.
- **been** → bin, corto.
- **caused** → kózd: una sola sílaba, no "káu-sed".
