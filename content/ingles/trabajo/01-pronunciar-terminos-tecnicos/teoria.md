# Pronunciar los términos técnicos

## En una frase

En una entrevista en inglés nadie te descalifica por tu acento, pero si dices "káche" en vez de **kásh**, el entrevistador no sabe de qué hablas. Esta unidad corrige las palabras técnicas que los hispanohablantes pronunciamos "como se escriben".

## Cómo se forma

Hay tres grupos de palabras, y cada uno tiene su regla:

| Grupo | Regla | Ejemplos |
|---|---|---|
| Siglas que se deletrean | Cada letra con su nombre en inglés | **API** éi pi ái, **UI** iú ái, **CSS** sí es és, **npm** én pi ém |
| Siglas que se leen como palabra | Se dicen de corrido | **JSON** yéison, **YAML** yámel, **regex** réyeks |
| Palabras con letras mudas o vocales "raras" | No se lee letra por letra | **queue** kiú, **cache** kásh, **height** jáit, **suite** suít |

Las letras en inglés, para deletrear siglas: **A** éi, **E** í, **I** ái, **G** yí, **J** yéi, **Q** kiú, **R** ar, **U** iú, **X** éks, **Y** uái.

- **SQL** se dice de dos formas y las dos son correctas: **és kiu él** o **síkuel**.
- **Git** lleva la "g" dura de "gato": **guít**, no "yít".
- Ejemplo: We store the data in a SQL database. → Guardamos los datos en una base de datos SQL.

## Errores típicos

| Palabra | Lo que se suele decir ✗ | Lo correcto ✓ |
|---|---|---|
| cache | "káche" o "kachéi" | **kásh** (igual que cash) |
| queue | "kéue" | **kiú** (igual que la letra Q) |
| width | "uít" | **uídz** (con la "th" entre los dientes) |
| height | "jéight" | **jáit** |
| data | "dáta" | **déira** |
| null | "nul" | **nál** |
| array | "árrai" | **aréi** |
| router | "róuter" con r fuerte | **ráurer** |
| schema | "eschéma" | **skíma** |
| suite | "suíte" | **suít** (igual que sweet) |
| Vite | "váit" | **vít** (es francés: rápido) |
| GitHub | "yít jub" | **guít jab** |
| Python | "pítón" | **páizon** |

- No pongas una "e" antes de "s" + consonante: **stack** no es "estak", **string** no es "estring", **schema** no es "eschema".
- La "u" de muchas palabras técnicas suena **a**: **null** nál, **public** páblik, **function** fánkshon, **GitHub** guít jab.

## Pronunciación

- **asynchronous** → eisínkronos: empieza con "éi", no con "a". Lo mismo en **async** éisink.
- **hierarchy** → jáirarki: la "h" suena como una "j" suave y la "ch" es "k".
- **algorithm** → álgorizem: la "th" va con la lengua entre los dientes, y no hay "o" al final.
- **recursion** → rikéryon: la "s" suena casi como la "y" del español de Argentina.
