# Aclarar y pensar en voz alta

## En una frase

En una entrevista técnica el silencio te juega en contra: el entrevistador quiere **oír cómo piensas**. Estas frases te dan algo que decir en cada paso, aunque todavía no sepas la respuesta.

## Cómo se forma

Sigue los cinco pasos y usa una frase modelo en cada uno:

| Paso | Frase modelo | En español |
|---|---|---|
| 1. Entender | **Just to clarify**, the input is always an array? | Solo para aclarar, ¿la entrada siempre es un array? |
|  | **Can I assume that** the numbers are positive? | ¿Puedo asumir que los números son positivos? |
|  | **What should happen if** the input is empty? | ¿Qué debería pasar si la entrada está vacía? |
| 2. Ejemplos | **So if I get** [1, 2, 3], **I should return** 6? | Entonces si recibo [1, 2, 3], ¿debo devolver 6? |
| 3. Plan | **Let me think out loud.** | Déjame pensar en voz alta. |
|  | **My first idea is a brute-force approach.** | Mi primera idea es una solución por fuerza bruta. |
|  | **I'll start with** the simple version **and then** optimize it. | Empiezo con la versión simple y luego la optimizo. |
| 4. Código | **Now I'm going to** loop through the array. | Ahora voy a recorrer el array. |
| 5. Probar | **Let me test it with an example.** | Déjame probarlo con un ejemplo. |
|  | **Let me walk you through my solution.** | Déjame explicarte mi solución paso a paso. |

- Para ganar tiempo sin quedarte callado: **Give me a second to think about it.** / **Hmm, let me see.**
- Para pedir una pista: **I'm a bit stuck. Could you give me a hint?**

## Errores típicos

- "Can I suppose that..." ✗ → "Can I **assume** that..." ✓. **Suppose** existe, pero en entrevistas se dice **assume**.
- "What happens if the input is empty?" ✓, pero "What pass if..." ✗: **pasar** aquí es **happen**.
- "I'm going to think in loud voice" ✗ → "I'm going to **think out loud**" ✓.
- "Let me explain you my solution" ✗ → "Let me **walk you through** my solution" o "Let me **explain my solution**" ✓.
- "I don't know" a secas ✗ → "**I'm not sure yet, but my first idea is...**" ✓. Siempre di algo que te acerque.
- "Is it okay if I use a map?" ✓ es mejor que usarlo sin avisar. Pregunta antes de usar algo poco común.

## Pronunciación

- **clarify** → klárifai, con fuerza al inicio.
- **assume** → asúm, y **assumption** → asámpshon.
- **approach** → apróuch: la fuerza va en la segunda sílaba.
- **out loud** → áut láud: las dos palabras riman.
