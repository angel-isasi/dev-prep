# Gramática para entrevistas

## En una frase

En una entrevista cuentas tu historia: lo que **hiciste**, lo que **llevas haciendo**, lo que **haces ahora** y lo que **harías distinto**. Cada idea tiene su tiempo verbal, y elegir bien hace que suenes seguro.

## Cómo se forma

| Quieres decir | Tiempo | Ejemplo |
|---|---|---|
| Un proyecto terminado, con fecha | Pasado simple | I **built** a weather app **last year**. → Hice una app del clima el año pasado. |
| Tu experiencia hasta hoy, sin fecha | Presente perfecto | I**'ve used** React **for** two years. → Uso React desde hace dos años. |
| Algo que empezó antes y sigue | Presente perfecto continuo | I**'ve been working on** a portfolio **since** May. → Estoy trabajando en un portafolio desde mayo. |
| Lo que haces en esta etapa | Presente continuo | I**'m currently learning** TypeScript. → Ahora estoy aprendiendo TypeScript. |
| Tu rol en un proyecto | Pasado + be responsible for | I **was responsible for** the frontend. → Yo me encargaba del frontend. |
| Herramienta y para qué | use X to + verbo | I **used** Redux **to manage** the state. → Usé Redux para manejar el estado. |
| Lo que harías distinto | would have + participio | I **would have written** more tests. → Habría escrito más tests. |
| Una costumbre que ya no tienes | used to + verbo | I **used to** write everything in one file. → Antes escribía todo en un solo archivo. |

- **For** + duración (for two years, for six months). **Since** + punto de inicio (since 2024, since May).
- Con **last year, in 2023, two months ago** siempre va pasado simple, nunca presente perfecto.

## Errores típicos

- "I **have built** it last year" ✗ → "I **built** it last year" ✓. Con una fecha terminada, pasado simple.
- "I **work** with React **since** two years" ✗ → "I**'ve worked** with React **for** two years" ✓.
- "I**'m working** here since March" ✗ → "I**'ve been working** here since March" ✓.
- "I was responsible **of**" ✗ → "I was responsible **for**" ✓.
- "I used React **for manage** the state" ✗ → "I used React **to manage** the state" ✓. Para un propósito, **to** + verbo.
- "I would have **use**" ✗ → "I would have **used**" ✓. Después de **have** va el participio.
- "I **use to** work at night" ✗ cuando hablas del pasado → "I **used to** work at night" ✓.

## Pronunciación

- **I've** → áiv, **I'd** → áid: dilas siempre contraídas, sin pronunciar "I have" completo.
- **would have** → wúdav, casi una sola palabra; **should have** → shúdav, **could have** → kúdav.
- **used to** → iústu: la "d" no se oye, y la "s" suena como "s", no como "z".
- Pasado con **-ed**: **worked** uérkt, **implemented** ímplementid, **designed** disáind. Solo suena "id" después de "t" o "d".
