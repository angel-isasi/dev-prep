## En una frase

Las oraciones con participio dicen en pocas palabras lo que en español armamos con "después de que", "como" o "que": Having fixed the bug, Ana deployed → Después de arreglar el bug, Ana desplegó. Son típicas del inglés escrito (documentación, correos, informes) y en una entrevista hacen que tu inglés suene maduro.

## Cómo se forma

| Forma | Idea | Ejemplo → Español |
|---|---|---|
| verbo + -ing | al mismo tiempo, o causa | Looking at the logs, I noticed a pattern. → Mirando los logs, noté un patrón. |
| Having + participio | algo que terminó antes | Having finished the tests, I opened the PR. → Después de terminar los tests, abrí el PR. |
| Not + -ing | causa negativa | Not knowing the code, I asked Tom. → Como no conocía el código, le pregunté a Tom. |
| participio (-ed o tercera forma) | sentido pasivo | Written in TypeScript, it's easy to maintain. → Como está escrita en TypeScript, es fácil de mantener. |
| Relativo reducido | quitas who/which/that + be | The developer (who is) working on it... / The files (that were) uploaded yesterday... |
| Absolutas (con sujeto propio) | contexto | Time permitting, we'll add dark mode. → Si hay tiempo, agregaremos el modo oscuro. |

Conectores que vienen de participios: **given that** (dado que), **provided that** (siempre que), **assuming that** (suponiendo que), **considering** (teniendo en cuenta), **judging by** (a juzgar por), **based on** (a partir de), **all things considered** (considerándolo todo).

**Regla de oro**: el sujeto del participio tiene que ser el mismo de la oración principal.
- Having reviewed the code, **Sarah** approved it ✓ (Sarah revisó y Sarah aprobó).
- Having reviewed the code, **the PR** was approved ✗ (¿el PR revisó el código?). Esto se llama *dangling participle* y es un error típico incluso de nativos.

## Errores típicos

- After finish the tests ✗ → After finishing the tests ✓ (después de una preposición, -ing)
- Having finished the tests, the PR was opened ✗ → Having finished the tests, I opened the PR ✓
- The developer who working on it ✗ → The developer working on it ✓ (si quitas who, quita también is)
- The files uploading yesterday ✗ → The files uploaded yesterday ✓ (los archivos no suben, alguien los sube: pasivo)
- Giving that we have no time ✗ → Given that we have no time ✓
- Considered the risk, we... ✗ → Considering the risk, we... ✓
- Given that we have time, so let's... ✗ → Given that we have time, let's... ✓ (no repitas el conector con *so*)

## Pronunciación

- La *-ed* suena "id" solo después de *t* o *d*: uploaded "aplóudid", stated "stéitid". Después de sonidos sordos suena "t": attached "atácht". En los demás, "d": logged "lógd".
- **given** → "guíven" y **having** → "jávin".
- **judging** → "yáyin": las dos *g* suenan como la *y* fuerte de "yo".
- **considering** → "konsíderin": fuerza en "sí".
