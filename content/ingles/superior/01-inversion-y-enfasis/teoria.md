## En una frase

El orden normal del inglés es sujeto + verbo. Para dar énfasis puedes romperlo con tres herramientas: la **inversión** después de una expresión negativa o restrictiva (Never have I seen...), las **cleft sentences**, que ponen el foco en una sola parte (What we need is more tests), y el **do enfático** (I do understand). Sirven para sonar convincente en una entrevista, una demo o un correo importante.

## Cómo se forma

**1. Inversión**: expresión negativa o restrictiva al inicio + auxiliar + sujeto + verbo. Es el orden de una pregunta, pero no es pregunta.

| Al inicio | Ejemplo → Español |
|---|---|
| Never, Seldom, Not once | Seldom do we deploy on Fridays. → Rara vez desplegamos los viernes. |
| Not only... but also | Not only did it crash, but it also deleted the logs. → No solo se cayó, sino que también borró los logs. |
| Only after, Only when, Not until | Only after we added logs did we find it. → Solo después de agregar logs lo encontramos. |
| No sooner... than, Hardly... when | No sooner had we shipped than the bugs started. → Apenas lanzamos, empezaron los bugs. |
| Under no circumstances, At no point, In no way | Under no circumstances should you push to main. → Bajo ninguna circunstancia debes hacer push a main. |
| Condicional sin if | Should you need help, let me know. → Si necesitas ayuda, avísame. |

- En presente y pasado simple aparece el auxiliar **do, does, did**: Never **did** I expect...
- Con Only after, Only when y Not until, la inversión va en la **segunda** parte.

**2. Cleft sentences**: dividen la frase para resaltar algo.
- **What** + sujeto + verbo + **is**: What we need is a clear plan. → Lo que necesitamos es un plan claro.
- **It was** + foco + **who / that**: It was Sarah who found the bug. → Fue Sarah quien encontró el bug.
- **All** + sujeto + verbo + **was**: All I did was restart it. → Lo único que hice fue reiniciarlo.
- **It wasn't until** + momento + **that**: It wasn't until Friday that we saw it. → Recién el viernes lo vimos.

**3. Do enfático**: do, does o did + verbo base, con fuerza en la voz. Sirve para contradecir o insistir: I **did** test it. She **does** know React.

Registro: la inversión suena formal o dramática. Úsala en presentaciones, correos importantes y entrevistas, no en un mensaje rápido de Slack. Las cleft y el do enfático suenan naturales en cualquier contexto.

## Errores típicos

- Never I have seen this ✗ → Never have I seen this ✓
- Not only it fixed the bug ✗ → Not only did it fix the bug ✓ (en pasado simple aparece did)
- Only after we added logs we found it ✗ → Only after we added logs did we find it ✓
- No sooner had we shipped when... ✗ → No sooner... **than** ✓ (when va con hardly)
- Was Sarah who found it ✗ → **It** was Sarah who found it ✓ (el It es obligatorio)
- All what I did was... ✗ → All I did was... ✓ ("todo lo que" no es all what)
- I did tested it ✗ → I did test it ✓ (después de do, verbo base)
- "Never have I seen this error" en Slack ✗ → "I've never seen this error" ✓ (la inversión suena teatral en un chat)

## Pronunciación

- En el do enfático la fuerza cae en **do**: "ái DÚ aprísheit". Si lo dices sin fuerza, suena como un error.
- En una cleft la voz sube en el foco: What we need is MORE TESTS.
- **circumstances** → "sérkomstansiz", fuerza en "sér".
- **seldom** → "séldom" y **no sooner** → "nóu súner".
