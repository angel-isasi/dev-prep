## En una frase

Algunos verbos van con **-ing** (I enjoy **coding**), otros con **to** (I decided **to apply**) y unos pocos cambian de sentido según cuál uses (I stopped **drinking** coffee ≠ I stopped **to drink** coffee). Es de lo que más delata a un hispanohablante, porque en español usamos el infinitivo para todo.

## Cómo se forma

| Van con -ing | Van con to |
|---|---|
| enjoy, avoid, finish, keep, mind, consider, practice, can't stand, can't help | want, need, decide, plan, hope, expect, agree, refuse, manage, learn, afford |

- I avoid pushing on Fridays. → Evito hacer push los viernes.
- I managed to fix it. → Logré arreglarlo.
- Querer que alguien haga algo: **want + persona + to**: I want you to review it → Quiero que lo revises.

Después de una **preposición**, siempre -ing: I'm good **at debugging**. Thanks **for helping**. **Before deploying**, run the tests. **Instead of copying**, write your own. Como sujeto también va -ing: **Testing** saves time.

Cambian de sentido:

| Verbo | + -ing | + to |
|---|---|---|
| stop | dejar de: I stopped drinking coffee. | parar para: I stopped to drink a coffee. |
| remember | recordar algo que ya pasó: I remember sending it. | acordarse de hacer: Remember to send it. |
| forget | olvidar algo que pasó: I'll never forget meeting her. | olvidarse de hacer: I forgot to save. |
| try | probar a ver si funciona: Try restarting the server. | intentar (cuesta): I tried to fix it, but I couldn't. |
| regret | arrepentirse: I regret leaving. | lamentar (anuncio formal): We regret to inform you... |

Los tres **used to**:
- **used to + verbo** = costumbre del pasado que ya no tienes: I used to work at night → Antes trabajaba de noche.
- **be used to + -ing** = estar acostumbrado: I'm used to working remotely.
- **get used to + -ing** = acostumbrarse (el proceso): I'm getting used to waking up early.

## Errores típicos

- I enjoy to code ✗ → I enjoy **coding** ✓
- I'm looking forward to meet you ✗ → I'm looking forward to **meeting** you ✓ (aquí *to* es preposición).
- Before to deploy, run the tests ✗ → **Before deploying** ✓ (calco de "antes de desplegar").
- I'm used to work remotely ✗ → I'm used to **working** remotely ✓
- I used to working at night ✗ → I used to **work** at night ✓
- I want that you help me ✗ → I want **you to help** me ✓ (calco de "quiero que me ayudes").
- I suggest you to use a map ✗ → I suggest **using** a map ✓

## Pronunciación

- **used to** se dice "iústa": la d no suena y la s es sorda. No digas "iúzd tu".
- **be used to** y **get used to** suenan igual: "iústa".
- La **-ing** final es una n nasal, sin una g fuerte: coding "kóuding", no "kódingue".
- **want to** se junta al hablar: "uána". Lo oirás mucho, pero escríbelo siempre want to.
