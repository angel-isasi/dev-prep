## En una frase

Las oraciones de relativo unen dos ideas y dicen **de quién o de qué** hablas: The developer who wrote this code left → El desarrollador que escribió este código se fue. Son clave en una entrevista técnica para definir conceptos ("A closure is a function that...") y para dar contexto sin hablar en frases sueltas.

## Cómo se forma

| Relativo | Para | Ejemplo |
|---|---|---|
| **who** | personas | The dev who fixed it is Sarah. → La dev que lo arregló es Sarah. |
| **that** / **which** | cosas | A closure is a function that remembers its scope. → Un closure es una función que recuerda su scope. |
| **whose** | de quién (posesión) | The client whose app crashed called us. → El cliente cuya app se cayó nos llamó. |
| **where** | lugar | This is the file where we keep the config. → Este es el archivo donde guardamos la configuración. |
| **when** | momento | We deploy on Fridays, when traffic is low. → Desplegamos los viernes, cuando hay poco tráfico. |

**Sin comas (defining)**: dice **cuál** de todos. The laptop that I use is old.
**Con comas (non-defining)**: agrega un dato extra; la frase se entiende sin él. Solo con **who** o **which**, nunca con that: My laptop, which is five years old, still works.
**, which** también puede referirse a toda la idea anterior (= lo cual): The build failed, which delayed the release.

**Omitir el relativo**: si después del relativo viene **otro sujeto**, el relativo es el objeto y se puede quitar. Al hablar es lo más común: the bug (that) I fixed, the person (who) I talked to. Si el relativo es el **sujeto**, no se quita: The dev who wrote this ✓.

**Preposición al final** (lo natural al hablar): the library I told you **about**, the team I work **with**. La forma formal es *the team with whom I work*.

En esta unidad usamos **who** para personas, **that** para cosas en las frases sin comas (lo más común en EE. UU.) y quitamos el relativo cuando es objeto.

## Errores típicos

- The man that he called me ✗ → The man **who called** me ✓ (no repitas el sujeto: who ya lo es).
- The library that I use it ✗ → The library **I use** ✓ (no repitas el objeto, como en "la librería que la uso").
- My mom, that is a teacher, ... ✗ → My mom, **who** is a teacher, ... ✓ (con comas nunca va that).
- The company where I work in ✗ → The company **where I work** ✓ o The company **I work in** ✓.
- The developer which wrote this ✗ → The developer **who** wrote this ✓ (which no se usa para personas).
- The person who's laptop broke ✗ → The person **whose** laptop broke ✓ (who's = who is).
- The build failed, what delayed the release ✗ → ..., **which** delayed the release ✓ (calco de "lo que").

## Pronunciación

- **whose** suena igual que who's: "júz", con z sonora.
- **who** "jú" y **whom** "júm": la w no suena.
- **which** "uích" suena igual que witch (bruja).
- En las frases con comas, haz una pausa corta en cada coma: My laptop, (pausa) which is old, (pausa) still works. La pausa le dice al otro que es un dato extra.
