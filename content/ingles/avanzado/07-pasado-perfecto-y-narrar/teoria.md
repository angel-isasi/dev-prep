# Pasado perfecto y narrar un incidente

## En una frase

El pasado perfecto (**had + participio**) marca lo que pasó **antes** de otro momento del pasado: *When I arrived, the meeting had started* (ya había empezado). Es la base para contar un bug o un incidente con orden, algo que te piden en casi toda entrevista.

## Cómo se forma

| Forma | Estructura | Ejemplo | Español |
|---|---|---|---|
| Pasado perfecto | had + participio | I had already pushed the fix. | Ya había subido el arreglo. |
| Negativa | hadn't + participio | We hadn't tested it on mobile. | No lo habíamos probado en celular. |
| Pregunta | had + sujeto + participio | Had you seen that error before? | ¿Habías visto ese error antes? |
| Pasado perfecto continuo | had been + -ing | The server had been failing for an hour. | El servidor llevaba una hora fallando. |

- Úsalo solo cuando el orden importa. Si ya cuentas en orden o usas **before / after**, basta el pasado simple: *I tested it before I pushed it.*
- Lo acompañan: **already** (ya), **just** (recién), **never... before** (nunca antes), **by the time** (para cuando), **by then** (para entonces).
- **had been + -ing** = "llevaba ... -ando": algo que venía pasando hasta ese momento.
- **'d** puede ser *had* o *would*: *I'd fixed it* = I had fixed it (va participio); *I'd fix it* = I would fix it (va verbo base).

Para contar un incidente, sigue este orden:
1. **Contexto**: We had just released a new checkout.
2. **Problema**: Users had been seeing errors for an hour before we noticed.
3. **Causa**: It turned out that someone had changed a config value.
4. **Acción**: I reverted the change and added an alert.
5. **Lección**: Since then, we review config changes too.

## Errores típicos

- "When I arrived, the meeting **already started**" ✗ → "When I arrived, the meeting **had already started**" ✓
- "I had **went**" ✗ → "I had **gone**" ✓: después de had va participio.
- "I **was waiting since** an hour" ✗ → "I **had been waiting for** an hour" ✓
- "Yesterday I **had fixed** a bug" (sin otro momento pasado) ✗ → "Yesterday I **fixed** a bug" ✓: no pongas had en todas las frases.
- "**It resulted** that the key had expired" ✗ → "**It turned out** that the key had expired" ✓

## Pronunciación

- **I'd, we'd, they'd** (con had): "áid", "uíd", "déid". La d casi no suena, así que fíjate si después viene un participio.
- **had been** se reduce en habla rápida: "ad bin". **been** suena "bin" en EE. UU.
- **hadn't** "jádent": no lo confundas con *haven't* "jávent".
- **turned out** se une: "térndaut".
