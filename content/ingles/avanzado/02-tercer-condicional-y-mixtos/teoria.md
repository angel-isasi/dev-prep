## En una frase

El tercer condicional imagina un pasado distinto del real: If I had tested it, the bug wouldn't have reached production → Si lo hubiera probado, el bug no habría llegado a producción. Lo usas para lamentos, lecciones aprendidas y postmortems, y en la típica pregunta de entrevista "What would you have done differently?". Los condicionales mixtos unen un pasado distinto con un presente distinto.

## Cómo se forma

| Tipo | Forma | Ejemplo |
|---|---|---|
| Tercero (pasado → pasado) | If + **had** + participio, **would have** + participio | If I had read the docs, I would have found the answer. → Si hubiera leído la documentación, habría encontrado la respuesta. |
| Mixto (pasado → presente) | If + **had** + participio, **would** + verbo | If I had studied English earlier, I would have more offers now. → Si hubiera estudiado inglés antes, ahora tendría más ofertas. |
| Mixto (presente → pasado) | If + **pasado simple**, **would have** + participio | If we were more careful, we wouldn't have broken the build. → Si fuéramos más cuidadosos, no habríamos roto el build. |

- Al hablar se contrae: If **I'd** known (= I had), I **would've** told you (= would have).
- **could have** + participio = pudo pasar: We could have lost everything → Pudimos perderlo todo.
- **might have** + participio = quizás pasó: It might have been the cache → Quizás fue la caché.
- **should have** + participio = debí hacerlo y no lo hice: I should have asked → Debí preguntar.
- Lamentos: **I wish I'd** + participio (ojalá hubiera...) e **If only I'd** + participio (si tan solo hubiera...).
- Más formal, sin if: **Had I known**, I would have called → De haberlo sabido, habría llamado.

## Errores típicos

- If I would have known, I would have told you ✗ → If I **had** known, I would have told you ✓ (would nunca va en la parte del if, aunque en español digas "hubiera").
- If I had known, I would told you ✗ → I **would have told** you ✓
- I wish I would have studied more ✗ → I wish I **had** studied more ✓ (lo oirás en EE. UU., pero se considera incorrecto).
- Hablando de ayer: If I knew it, I would have told you ✗ → If I **had known** it ✓
- I would of done it ✗ → I **would have** (would've) done it ✓: suenan igual, pero *of* es un error de escritura.
- I must have tested it (para decir "debí probarlo") ✗ → I **should have** tested it ✓ (must have = seguro que lo probé).

## Pronunciación

- **would have** se dice "údav", casi una sola palabra; **could have** "kúdav" y **should have** "shúdav".
- **I'd** "áid" es muy corto: escucha bien, porque If I'd known e If I known (que no existe) suenan casi igual.
- **hadn't** "jádent": la h suena como una j suave.
- **wouldn't have** se une: "údentav".
